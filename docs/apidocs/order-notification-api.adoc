== 개요

구매자의 주문 상태 변경 알림을 조회하고 읽음 처리하는 API입니다.

=== 공통 응답 형식

모든 API는 아래 형식으로 응답합니다.

[source,json]
----
{
  "success" : true,
  "status"  : 200,
  "message" : "...",
  "data"    : { ... },
  "timestamp" : "2024-01-01T12:00:00"
}
----

[cols="1,1,3"]
|===
|필드 |타입 |설명

|`success`
|Boolean
|요청 성공 여부

|`status`
|Number
|HTTP 상태 코드

|`message`
|String
|응답 메시지

|`data`
|Object \| null
|응답 데이터 (실패 시 null)

|`timestamp`
|String
|응답 시간 (ISO 8601)
|===

=== 공통 오류 코드

[cols="1,1,3"]
|===
|HTTP 상태 |오류 상황 |message

|`404`
|존재하지 않는 구매자
|존재하지 않는 사용자입니다.

|`404`
|존재하지 않는 알림
|알림이 존재하지 않습니다.

|`401`
|인증 실패
|인증이 필요합니다.
|===
